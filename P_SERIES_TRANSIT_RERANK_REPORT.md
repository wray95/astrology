# P-Series Transit-Informed Re-Rank Decision

## Result

The Q candidate movement data does **not support a defensible re-ranking of P1–P9**. There are 0 verified P event rows and no verified Q outcome labels for wealth, poverty, success or failure. The 161 date-level Q candidates are dominated by death records and are not an outcome-controlled transit sample.

Therefore the evidence-based decision is:

> **No transit-based rank change. Retain the previous P-series ranking only as a prior exploratory ranking, not as a result supported by the new event data.**

## Why a transit re-rank would be premature

A valid P re-rank requires a pre-specified model trained on verified Q outcomes, followed by P-only scoring. Current Q data has no verified success, wealth, marriage, childbirth or failure outcomes. It would be circular to rank P people using patterns that have not been established in Q.

Next valid step: verify Q candidate dates, label outcomes objectively, build matched controls, fit the model on Q, lock it, then score P separately.
