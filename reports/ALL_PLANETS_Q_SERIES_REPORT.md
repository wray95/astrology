# All-Planet Q-Series Date-Only Analysis

## Run

The same date-only method was applied to all 5,010 Q-series people. P1–P9 remain separate.

For every Q record, the output contains the UTC-noon midpoint reference position of:

- Sun
- Moon
- Mercury
- Venus
- Mars
- Jupiter
- Saturn
- Uranus
- Neptune
- Pluto
- Mean Rahu
- Derived Ketu

For each body the output includes:

- sidereal longitude
- zodiac sign
- degree within sign
- daily speed
- retrograde/direct status
- nakshatra

## Cycle interpretation

Approximate astronomical cycles are included as research metadata:

| Body | Approximate cycle |
|---|---:|
| Sun | 1 year |
| Moon | 27.3 days sidereal |
| Mercury | About 1 year, variable because of retrograde motion |
| Venus | About 1 year, variable because of retrograde motion |
| Mars | About 1.88 years |
| Jupiter | About 11.86 years |
| Saturn | About 29.46 years |
| Uranus | About 84 years |
| Neptune | About 164.8 years |
| Pluto | About 248 years |
| Rahu/Ketu | About 18.6 years, retrograde nodes |

These cycles identify possible return windows. They do not indicate that a life event will occur. To test return-event associations, each Q person needs a verified event timeline and matched control periods.

## Date-only caution

UTC noon is a reproducible reference instant, not an assumed birth time. The Moon, Mercury, Venus, combustion, aspects and lunar calendar features may change during the civil date. The CSV should therefore be combined with daily interval/sensitivity fields before making a hypothesis.
