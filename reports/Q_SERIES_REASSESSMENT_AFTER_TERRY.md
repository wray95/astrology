# Q-Series Reassessment After Terry Crews Case

## Data separation

Terry Crews is not present in the current 5,010-person Q source roster. His Saturn-return case is therefore an external benchmark and does not change Q-series counts.

The Q tests were rerun with the same cohort and same pre-registered phases:

- pre-ingress within 180 days
- natal Saturn-sign phase
- exact return within 3°
- post-sign window

## Q result remains

| Phase | Candidate events | Controls |
|---|---:|---:|
| Pre-ingress | 9/161 = 5.6% | 84/2,980 = 2.8% |
| Natal-sign phase | 15/161 = 9.3% | 210/2,980 = 7.0% |
| Exact return ≤3° | 4/161 = 2.5% | 42/2,980 = 1.4% |
| Post-sign phase | 2/161 = 1.2% | 81/2,980 = 2.7% |

## Reassessment

The Terry Crews sequence strengthens the **case-study hypothesis** that a Saturn return may coincide with career closure and reorganization, with public success following afterward. It does not increase the statistical Q sample.

The Q-series evidence remains weakly compatible with a pre-ingress/natal-sign sequence, but it is not yet a verified rags-to-riches or success test because the Q event rows are mostly candidate death/career extractions and lack outcome labels.

## Current working model

The most defensible version is:

> Saturn phases may be associated with transition timing—career closure, responsibility, restructuring and delayed consolidation—rather than directly predicting success or failure.

This model must still be tested against verified positive, negative and null cases.
