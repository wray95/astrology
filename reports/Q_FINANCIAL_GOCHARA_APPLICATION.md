# Q-Series Financial Gochara Application

Applied all financial techniques that are valid for date-only Q data across 5,010 people.

## Applied

- Jupiter sign, degree, retrograde and return baseline
- Saturn pre-ingress, natal-sign and exact-return windows
- Venus sign, degree, retrograde and return baseline
- Rahu/Ketu sign, degree and node-return baseline
- Candidate event-date planetary movement fields

## Not applied

- 2nd, 6th, 10th and 11th houses
- House lords
- Dasha/Antardasha
- D9 and D10
- House-based wealth yogas

Those require a reliable birth time.

## Result

- Q people: 5,010
- Verified financial outcomes: 0
- Verified rags-to-riches outcomes: 0
- Verified financial-loss outcomes: 0

The financial feature table is:

`outputs/q_financial_gochara/q_financial_features.csv`

This is a feature baseline, not a wealth prediction result. To test financial Gochara, add independently sourced first-income, business-founding, company-sale, IPO, net-worth-threshold, bankruptcy and financial-recovery dates, then compare those events with the Saturn/Jupiter/Venus/Rahu/Ketu windows.
