# Q Saturn Sign-Cycle Outcome Test

## Correct cycle rule

Saturn returns to the **same natal sign** after approximately 29–30 years. The sign immediately before that return is the pre-ingress phase:

- Natal Pisces → Aquarius before Pisces ingress
- Natal Aries → Pisces before Aries ingress
- Natal Taurus → Aries before Taurus ingress

The test must distinguish the pre-ingress sign from the actual natal-sign return.

## Q-series run

- Q people: 5,010
- Usable candidate event rows: 161
- Natal Saturn signs represented: 12
- Verified wealth/king/downfall labels: 0

The event sample contains mainly death and candidate career records, so it cannot answer whether a sign cycle creates wealth, political power or downfall.

## Available event-phase counts by natal Saturn sign

The full per-event cross-reference is in `events_by_natal_saturn_sign.csv`. The `summary.json` file contains every sign's phase and event-type counts.

The current evidence should be treated as timing infrastructure, not an outcome result. No sign can be called a wealth sign, king-making sign or downfall sign from these rows because the required outcome labels are absent.

## Required outcome table

For every Q person, add dated, sourced outcome rows such as:

- wealth gain / net-worth threshold
- poverty or financial loss
- election victory / political office
- election defeat / resignation
- career debut / breakthrough
- marriage / divorce
- childbirth
- bankruptcy / incarceration / illness / death

Then compare each event with:

1. 180-day pre-ingress window
2. Saturn natal-sign phase
3. Exact-degree return, e.g. ≤3°
4. Post-sign phase
5. Matched same-person control dates

Only after that can we test whether Pisces, Aries, Taurus or another natal Saturn sign has a different distribution of wealth, political success or downfall outcomes.
