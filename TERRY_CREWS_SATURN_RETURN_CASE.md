- Birth date: 30 July 1968

## Classification

This is a strong sequence for the working model:

1. **Career closure/pressure:** NFL retirement in 1997, shortly before the exact return.
2. **Exact Saturn return:** approximately May 1998.
3. **New structural beginning:** first film-production project in 1998.
4. **Visible breakthrough:** television role in 1999, after the exact return.

This is not simply “Saturn caused fame.” It is more precisely:

> Existing career ends → exact Saturn return → new career foundation → public breakthrough.

Terry Crews is therefore a high-value benchmark for the delayed-transition version of the Saturn-return hypothesis.
