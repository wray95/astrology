The sign passage is a broad transit window. The exact-degree return is a narrower astronomical event. They should not be treated as interchangeable.

### What happened to P4?

The repository describes P4's occupation/career archetype, but it does **not** contain verified dated records for P4's business founding, marriage, promotions, wealth changes, failures or other life events. Therefore this run cannot claim what happened during the 1995–98 or 2025–28 windows. Those dates are prediction/research windows only.

## Proper test once event data exists

For each Q person and event:

1. Link the event to Q ID, not only name.
2. Record event date precision and source reliability.
3. Calculate whether the event occurred in the first/second Saturn return window.
4. Compare with matched non-return periods for the same person.
5. Separate positive events from negative events.
6. Adjust for age, historical period, season, country and observation time.
7. Split discovery and validation people before testing.

Possible outcome groups:

- employment / promotion
- marriage / divorce
- childbirth / child loss
- wealth gain / bankruptcy or financial loss
- achievement / public success
- illness / accident / death

Until those event rows are supplied, the scientifically correct result is **not yet determined**.
