# EVENTS SOURCES

## Status: ⚠️ INCOMPLETE — No dated events collected yet

## Methodology
Events should be sourced from:
- Wikipedia biography pages
- Astrodatabank biography entries
- Published biographies/autobiographies
- Newspaper archives
- Official records

## Collection Rules
1. Every event must have: exact date (YYYY-MM-DD), source URL, reliability level
2. Reliability: VERIFIED (multiple sources) / PARTIALLY_VERIFIED (single source) / UNVERIFIED
3. Event categories: career_breakthrough, award, marriage, divorce, birth_child, 
   wealth_milestone, bankruptcy, illness, accident, death, retirement, career_change, 
   political_rise, political_loss

## Current State
Only event TYPES are recorded. Specific event DATES must be collected from 
biographies before any astrological event-timing analysis can proceed. 

See `events/documented_events.csv` for the placeholder structure.
