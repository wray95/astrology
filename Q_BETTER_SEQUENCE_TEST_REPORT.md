# Improved Q-Series Sequence Test

## Design

The Anura/Elon hypothesis was translated into pre-defined Saturn phases:

- **Pre-ingress pressure:** within 180 days before Saturn enters the person's natal Saturn sign
- **Natal-sign phase:** Saturn in the natal Saturn sign
- **Exact return:** Saturn within 3° of the natal Saturn degree
- **Post-sign phase:** within 180 days after the natal-sign passage

For each candidate event, up to 20 control dates were sampled for the same person in the same calendar month, before the event. This controls seasonality better than the earlier random-lifespan test, though it remains preliminary.

## Pooled results

| Phase | Candidate events | Controls |
|---|---:|---:|
| Pre-ingress pressure | 9/161 = 5.6% | 84/2,980 = 2.8% |
| Natal-sign phase | 15/161 = 9.3% | 210/2,980 = 7.0% |
| Exact return ≤3° | 4/161 = 2.5% | 42/2,980 = 1.4% |
| Post-sign phase | 2/161 = 1.2% | 81/2,980 = 2.7% |

Descriptive pooled ratios are approximately:

- Pre-ingress: 1.98× control exposure
- Natal-sign phase: 1.32×
- Exact return: 1.76×
- Post-sign phase: 0.46×

These are not final risk ratios because each event has multiple controls and several rows can belong to one person.

## By event type

- Death candidates: 8 pre-ingress, 13 natal-sign phase, 4 exact-return, 2 post-sign.
- Debut/career candidates: 1 pre-ingress, 1 natal-sign phase, 0 exact-return.
- Marriage/spouse candidates: 0 pre-ingress, 1 natal-sign phase, 0 exact-return.
- Incarceration candidate: 0 in all Saturn return phases.

## Interpretation

This is the first Q-series result that resembles the proposed sequence: candidate dates are somewhat more common in the pre-ingress and natal-sign phases than in the same-month controls. Exact-return exposure is also slightly higher, but it contains only four events.

The result does **not** establish a rags-to-riches or success effect because:

- There are no verified Q wealth or success trajectories.
- The sample is dominated by death candidates.
- Candidate events came from inconsistent biography fields.
- The controls are preliminary and not yet person-bootstrap corrected.
- The same apparent pattern may result from historical clustering or Saturn's calendar cycle.

The correct next test is to manually verify wealth, career, marriage, childbirth, success, bankruptcy and failure dates, then run person-level bootstrap/permutation tests with a locked outcome definition.
